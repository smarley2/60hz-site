# 60Hz Energias — site de encerramento

Landing page estática e responsiva para o encerramento das atividades da 60Hz Energias.

## Pré-visualizar antes de alterar o DNS

1. No GitHub, abra **Settings → Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch **main** e a pasta **/(root)**.
4. Clique em **Save**.
5. Aguarde o GitHub publicar o site e abra:

   `https://smarley2.github.io/60hz-site/`

O domínio `60hz.com.br` ainda não é necessário para esse teste.

## Domínio personalizado

O arquivo `CNAME` não é adicionado nesta primeira versão. Depois da aprovação visual, configure o DNS e adicione `www.60hz.com.br` como domínio personalizado no GitHub Pages.

## Suporte

O botão de atendimento abre um e-mail para `atendimento@60hz.com.br`.
